Privacy policy

Shorts Studio · last updated 30 September 2026

Shorts Studio is a personal tool that publishes videos to its owner's YouTube channels, Byte Frame Visuals and SportFrameVisuals. Only the owner signs in to it. This policy explains what it does with Google user data.

Data the tool accesses

  • Through the YouTube Data API: uploading videos with their title, description and tags, and reading the status and public statistics (views, likes, comments) of the channels' own videos.
  • Through the YouTube Analytics API: reading the channels' own reports (average view duration, average percentage viewed, subscribers gained and views by country).

The tool does not access data about other people, and it does not read comments, messages or subscriber identities.

How the data is used and stored

The data is used only to publish the owner's videos and to show the owner how they perform. It is stored on the owner's own computer, in a local database, and is not uploaded anywhere else. Sign-in tokens are stored encrypted on the same computer.

Sharing

Google user data is not sold, shared with third parties, or used for advertising.

YouTube API Services

Shorts Studio uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Removing access and data

Access can be revoked at any time on the Google Account third-party connections page. After revoking it, the tool can no longer reach the channels; locally stored statistics are deleted on request to the contact below.

Changes

Changes to this policy are published on this page with a new date.
